# Agent Reach

Agent Reach provides AI coding agents and local developer workflows with seamless access to live internet data, web documentation, and cross-platform information retrieval without relying on paid scraper APIs.

## Capabilities

1. **Live Web & Documentation Search**: Look up latest framework changes, library releases, API specs, and online examples.
2. **Multi-Platform Intelligence**: Extract public discussions, issues, and solutions from developer ecosystems (GitHub, Reddit, Twitter/X, developer forums).
3. **No-API-Key Local Scraping**: Integrates local-first fetching and parsing strategies to query documentation and code snippets directly.
4. **Agent Integration**: Callable as a subagent or skill workflow within Antigravity, OpenClaw, or terminal tasks.

## Usage Guide

- When investigating external libraries, UI component collections (e.g., React Bits, Aceternity, Shadcn, Magic UI), or third-party documentation, use Agent Reach alongside `ego-browser` or search tools.
- Maintain local-first data caching when pulling remote assets or component source codes into the project.
