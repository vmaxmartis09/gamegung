# Policy: Không sử dụng GitHub hoặc GitLab

- Tuyệt đối không sử dụng tài khoản GitHub hoặc GitLab của người dùng.
- Không kết nối, tương tác hay push/pull với bất kỳ dịch vụ GitHub hay GitLab nào.
- Chỉ làm việc với mã nguồn cục bộ (local) và các dịch vụ đã được cấu hình cụ thể (như Supabase).
